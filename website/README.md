# Gmail Notifier for KDE

Website for Gmail Notifier - lightweight system tray email notifier for KDE on Linux.

**[gmail-notifier.elevatech.xyz](https://gmail-notifier.elevatech.xyz)**

Built with [Astro](https://astro.build).

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```
